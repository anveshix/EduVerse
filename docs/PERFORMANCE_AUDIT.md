# Performance audit

Measured 2026-11-13 with headless Chromium `153.0.8010.0` (Playwright `1.65.0` + `@sparticuz/chromium` SwiftShader WebGL2) on the container's CPU and local Node static server. Reproduce with `npm run perf:size`, `npm run perf:throttle`, `npm run smoke`, and `npm run smoke:mobile`. **Emulation, not hardware:** no physical Android phone, discrete GPU, or real cellular network was used.

Notes:

- Home's synchronous JS static boot closure (`src/main.js` and immediate ES imports measured by `tools/verify-architecture.mjs`) is **`79.0 KB` raw across `16` modules** — `vendor/d3/d3-viz.esm.js` (`101.3 KB`), `teacher-meta.js`, `i18n/ui.js`, `nep-cbq.js`, `class-x-bridge.js`, and theme 3D dioramas (`diorama/part1.js`, `diorama/part2.js`) stay deferred until navigated to.
- `<link rel="modulepreload">` hints (`13` modules in `index.html`) parallelize Home's critical-path ESM fetches.

## 2. Degraded conditions (emulated by `tests/perf-throttle.cjs`)

Network `400 kbit/s` with `400 ms` RTT, CPU slowed `6×`, gzip responses, cold cache, Service Worker blocked:

| Page | Seconds until usable | Slider input → redraw |
|---|---|---|
| Home (`#/`) | **4.4 s** | – |
| T09 Price Puzzle | **8.9 s** | **14.9 ms** |
| T16 Finance | **8.7 s** | **10.8 ms** |
| T11 Ecosystems | **9.9 s** | **29.0 ms** |

On unthrottled headless Chromium (`npm run smoke`, 1100 px), themes reached an interactive module in `470–1,142 ms` with slider input latency of `0.21–2.35 ms` across 20 sweeps and JS heap readings of `25 MB`.

## 3. Offline (`sw.js`)

`sw.js` (generated by `npm run sw`) precaches **116** runtime files (`117` entries including `./`). Verified live in Chromium via `tests/perf-throttle.cjs`:
- `cachedFiles`: **117**
- `homeLoads`: **`true`**
- `labLoads` (`#/theme/T16`): **`true`**
- `labInteractive` (slider response offline): **`true`**

## 4. Responsive & Accessibility Layout

- `npm run smoke` (`1100 px`) & `npm run smoke:mobile` (`360 px` touch): `hOverflowPx: 0` and `NO ERRORS` across all **16 / 16** themes (`T01`–`T16`), plus Home, `#/bridge`, and `#/portfolio`.
- `npm run a11y` (`390 px` touch): `smallTargets: 0` (`>= 44 px`), `unlabelledSvg: 0`, `unlabelledRanges: 0`, `tabKeyboard: true` across all **16 / 16** themes.

## 5. Still Outside Sandbox Scope

- Frame rate & GPU thermals on physical low-end Android phones (`2 GB` RAM), real cellular network conditions, and physical WebXR headset sessions.
- Optimizing hero/plate JPEG sizes further if mobile first-visit byte budgets need tightening.
